# i-transfer
A simple, light-weight sharing app

## Usage

1. **Add files** — drop the files you want to share into this directory.
2. **Start the server**:
   ```bash
   php -S 0.0.0.0:8000
   ```
3. **Share** — open `http://<your-ip>:8000` and click **Download** next to any file.

> Files are listed automatically (newest first). `index.php` and hidden files are excluded.
